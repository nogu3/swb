# swb CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the full initial `swb` CLI: BLE passive scan (JSONL) with MeterProCO2 decoding, `models`, and the three cloud commands (`devices`, `status`, `cmd`) against SwitchBot API v1.1.

**Architecture:** Binary + thin lib crate. `main.rs` does clap parsing/dispatch only; `emit.rs` owns output line types, error type, and serialization; `ble/` (btleplug scan loop + pure parsers) and `cloud/` (ureq one-shot client + HMAC signing) are independent and both depend on `emit`. Async only inside the BLE scan loop (current-thread tokio runtime); everything else is sync.

**Tech Stack:** Rust stable edition 2021, clap 4 (derive), serde/serde_json, toml, tracing, btleplug 0.11, tokio (rt+time), futures, ureq 2, hmac/sha2/base64, uuid (v4), time 0.3.

**Spec documents (read both before any task):**
- `CLAUDE.md` — authoritative spec (output schema, exit codes, conventions)
- `docs/superpowers/specs/2026-07-15-swb-cli-design.md` — pinned decisions D1–D9

## Global Constraints

- Public OSS repo: code, comments, commit messages in English. No private hostnames/device IDs anywhere; placeholders only (`XX:XX:...`, `DEVICE_ID`).
- stdout is pure structured JSON (JSONL for scan); diagnostics/errors go to stderr (`tracing` + one-line `{"error":{"kind":"...","detail":"..."}}`).
- Exit codes: 0 success, 2 usage, 3 timeout, 4 BLE adapter, 5 auth, 6 device/API rejection, 1 other.
- No panics in library code: `unwrap`/`expect` only in tests. (`src/main.rs` is also panic-free.)
- Credentials (`SWITCHBOT_TOKEN`/`SWITCHBOT_SECRET`, config `[credentials]`) never logged, never in error messages, never in fixtures.
- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test` must pass — without hardware, network, or credentials.
- Never emit `null` values or guessed decodes; omit what cannot be decoded; unknown payloads are still emitted losslessly.
- Conventional Commits.
- **Build note for this machine:** system `libdbus-1-dev`/`pkg-config` are missing; all `cargo` commands that compile btleplug's Linux backend must use `--features vendored-dbus` (e.g. `cargo test --features vendored-dbus`). CI installs the system lib and builds without the feature.

```rust
//! Output line types, error type, and serialization.
//!
//! stdout is pure structured JSON; errors are one-line JSON on stderr.

use std::fmt::Write as _;

use serde::Serialize;
use time::macros::format_description;
use time::OffsetDateTime;

pub type Values = serde_json::Map<String, serde_json::Value>;

/// Lowercase hex, no separators.
pub fn hex(bytes: &[u8]) -> String {
    let mut s = String::with_capacity(bytes.len() * 2);
    for b in bytes {
        let _ = write!(s, "{b:02x}");
    }
    s
}

/// RFC 3339 UTC with millisecond precision, e.g. `2026-07-15T06:00:00.123Z`.
pub fn now_ts() -> String {
    let fmt = format_description!(
        "[year]-[month]-[day]T[hour]:[minute]:[second].[subsecond digits:3]Z"
    );
    OffsetDateTime::now_utc().format(&fmt).unwrap_or_default()
}

/// One BLE scan JSONL line. `mfr_hex` is the raw manufacturer data as
/// transmitted (little-endian company ID prefix included) — the lossless
/// layer. `model`/`values` appear only when a decode dictionary matched.
#[derive(Debug, Serialize)]
pub struct ScanLine {
    pub ts: String,
    pub addr: String,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub rssi: Option<i16>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub mfr_hex: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub svc_hex: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub model: Option<&'static str>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub values: Option<Values>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ErrorKind {
    Usage,
    Timeout,
    Adapter,
    Auth,
    Device,
    Other,
}

impl ErrorKind {
    pub fn exit_code(self) -> i32 {
        match self {
            ErrorKind::Usage => 2,
            ErrorKind::Timeout => 3,
            ErrorKind::Adapter => 4,
            ErrorKind::Auth => 5,
            ErrorKind::Device => 6,
            ErrorKind::Other => 1,
        }
    }

    pub fn as_str(self) -> &'static str {
        match self {
            ErrorKind::Usage => "usage",
            ErrorKind::Timeout => "timeout",
            ErrorKind::Adapter => "adapter",
            ErrorKind::Auth => "auth",
            ErrorKind::Device => "device",
            ErrorKind::Other => "other",
        }
    }
}

#[derive(Debug)]
pub struct SwbError {
    pub kind: ErrorKind,
    pub detail: String,
}

impl SwbError {
    fn new(kind: ErrorKind, detail: impl Into<String>) -> Self {
        SwbError {
            kind,
            detail: detail.into(),
        }
    }

    pub fn usage(detail: impl Into<String>) -> Self {
        Self::new(ErrorKind::Usage, detail)
    }

    pub fn timeout(detail: impl Into<String>) -> Self {
        Self::new(ErrorKind::Timeout, detail)
    }

    pub fn adapter(detail: impl Into<String>) -> Self {
        Self::new(ErrorKind::Adapter, detail)
    }

    pub fn auth(detail: impl Into<String>) -> Self {
        Self::new(ErrorKind::Auth, detail)
    }

    pub fn device(detail: impl Into<String>) -> Self {
        Self::new(ErrorKind::Device, detail)
    }

    pub fn other(detail: impl Into<String>) -> Self {
        Self::new(ErrorKind::Other, detail)
    }

    /// Machine-readable stderr line.
    pub fn to_json(&self) -> String {
        serde_json::json!({
            "error": { "kind": self.kind.as_str(), "detail": self.detail }
        })
        .to_string()
    }
}

impl std::fmt::Display for SwbError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "{}: {}", self.kind.as_str(), self.detail)
    }
}

impl std::error::Error for SwbError {}

/// Emit one JSON document/line on stdout.
pub fn print_json<T: Serialize>(value: &T) {
    match serde_json::to_string(value) {
        Ok(s) => println!("{s}"),
        Err(e) => tracing::error!("failed to serialize output: {e}"),
    }
}
```

//! Model detection and decode dispatch for SwitchBot advertisements.
//!
//! Decode dictionaries are optional enrichment: an unknown model tag or
//! undecodable payload returns `None` and the caller emits the raw line.

pub mod meter_co2;

use crate::emit::Values;

/// Bluetooth SIG company identifier for Woan Technology (SwitchBot).
pub const COMPANY_ID: u16 = 0x0969;

/// A model with BLE decode support (static info for `swb models`).
pub struct ModelInfo {
    pub model: &'static str,
    pub tag: char,
    pub values: &'static [&'static str],
}

pub const MODELS: &[ModelInfo] = &[ModelInfo {
    model: "MeterProCO2",
    tag: '5',
    values: &["temperature", "humidity", "co2", "battery"],
}];

pub struct Decoded {
    pub model: &'static str,
    pub values: Values,
}

/// Decode one advertisement.
///
/// `mfr` is the 0x0969 manufacturer payload *without* the 2-byte company
/// ID; `svc` is the fd3d service-data payload. The model tag lives in
/// `svc[0]` (bit 7 = encrypted flag, masked off). Without service data we
/// do not guess a model.
pub fn decode(mfr: Option<&[u8]>, svc: Option<&[u8]>) -> Option<Decoded> {
    let tag = svc?.first()? & 0x7f;
    match tag {
        b'5' => meter_co2::parse(mfr, svc).map(|values| Decoded {
            model: "MeterProCO2",
            values,
        }),
        _ => None,
    }
}

//! SwitchBot Meter Pro CO2 (model tag '5').
//!
//! Format reference: pySwitchbot `adv_parsers/meter.py` +
//! `adv_parsers/_sensor_th.py`. Fixtures: `tests/fixtures/ble/meter_pro_co2.txt`.

use serde_json::json;

use crate::emit::Values;

/// Sensor spec range is 400-9999 ppm; larger values are transient
/// artifacts and are dropped rather than emitted.
const CO2_MAX_PPM: u16 = 9999;

pub fn parse(mfr: Option<&[u8]>, svc: Option<&[u8]>) -> Option<Values> {
    let mut values = Values::new();

    if let Some(m) = mfr {
        if m.len() >= 11 {
            // byte 9: bit 7 = sign (1 = positive), bits 6..0 = integer C;
            // byte 8 low nibble = tenths.
            let sign = if m[9] & 0x80 != 0 { 1.0 } else { -1.0 };
            let temperature =
                sign * (f64::from(m[9] & 0x7f) + f64::from(m[8] & 0x0f) / 10.0);
            values.insert("temperature".to_string(), json!(temperature));
            values.insert("humidity".to_string(), json!(m[10] & 0x7f));
        }
        if m.len() >= 15 {
            let co2 = u16::from_be_bytes([m[13], m[14]]);
            if co2 <= CO2_MAX_PPM {
                values.insert("co2".to_string(), json!(co2));
            }
        }
    }

    if let Some(s) = svc {
        if s.len() >= 3 {
            values.insert("battery".to_string(), json!(s[2] & 0x7f));
        }
    }

    if values.is_empty() {
        None
    } else {
        Some(values)
    }
}
```

use base64::engine::general_purpose::STANDARD;
use base64::Engine as _;
use hmac::{Hmac, Mac};
use sha2::Sha256;

use crate::emit::SwbError;

/// Base64 HMAC-SHA256 of `token + t + nonce`, keyed by `secret`.

    secret: &str,
    t_millis: u64,
    nonce: &str,

use serde_json::{json, Value};

use crate::emit::{ErrorKind, SwbError};
use types::ApiResponse;

pub const DEFAULT_BASE: &str = "https://api.switch-bot.com";

pub struct Client {
    token: String,
    secret: String,
    base: String,
    agent: ureq::Agent,
}

impl Client {
    pub fn new(token: String, secret: String) -> Self {
        Self::with_base(token, secret, DEFAULT_BASE.to_string())
    }

    /// `base` override exists for tests against a local mock server.
    pub fn with_base(token: String, secret: String, base: String) -> Self {
        let agent = ureq::AgentBuilder::new()
            .timeout(std::time::Duration::from_secs(30))
            .build();
        Self {
            token,
            secret,
            base,
            agent,
        }
    }

    pub fn get(&self, path: &str) -> Result<Value, SwbError> {
        self.request("GET", path, None)
    }

    pub fn post(&self, path: &str, body: &Value) -> Result<Value, SwbError> {
        self.request("POST", path, Some(body))
    }

    fn request(
        &self,
        method: &str,
        path: &str,
        body: Option<&Value>,
    ) -> Result<Value, SwbError> {
        let t = current_millis()?;
        let nonce = uuid::Uuid::new_v4().to_string();
        let sig = auth::sign(&self.token, &self.secret, t, &nonce)?;
        let url = format!("{}{}", self.base, path);
        tracing::debug!(method, path, "cloud request");

        let request = self
            .agent
            .request(method, &url)
            .set("Authorization", &self.token)
            .set("sign", &sig)
            .set("t", &t.to_string())
            .set("nonce", &nonce)
            .set("Content-Type", "application/json; charset=utf-8");

        let result = match body {
            Some(b) => request.send_string(&b.to_string()),
            None => request.call(),
        };

        let text = match result {
            Ok(response) => response
                .into_string()
                .map_err(|e| SwbError::other(format!("reading response: {e}")))?,
            Err(ureq::Error::Status(401, _)) => {
                return Err(SwbError::auth("HTTP 401: invalid token or signature"))
            }
            Err(ureq::Error::Status(code, response)) => {
                let text = response.into_string().unwrap_or_default();
                return Err(SwbError::device(format!("HTTP {code}: {text}")));
            }
            Err(ureq::Error::Transport(t)) => {
                let msg = t.to_string();
                let kind = if msg.contains("timed out") {
                    ErrorKind::Timeout
                } else {
                    ErrorKind::Other
                };
                return Err(SwbError { kind, detail: format!("request failed: {msg}") });
            }
        };

        parse_response(&text)
    }
}

/// `statusCode == 100` → body; other statusCode → device error;
/// non-JSON → pass the raw text through instead of failing.
pub fn parse_response(text: &str) -> Result<Value, SwbError> {
    match serde_json::from_str::<ApiResponse>(text) {
        Ok(resp) if resp.status_code == 100 => Ok(resp.body),
        Ok(resp) => Err(SwbError::device(format!(
            "statusCode {}: {}",
            resp.status_code, resp.message
        ))),
        Err(_) => Ok(json!({ "raw": text })),
    }
}

fn current_millis() -> Result<u64, SwbError> {
    std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .map(|d| d.as_millis() as u64)
        .map_err(|e| SwbError::other(format!("system clock before epoch: {e}")))
}

//! BLE backend: passive scan loop and advertisement parsers.
//!
//! Async stays at this I/O boundary: a current-thread tokio runtime lives
//! only for the duration of the scan; parsers are pure sync functions.

pub mod parse;

use std::collections::HashSet;
use std::time::Duration;

use btleplug::api::{Central, CentralEvent, Manager as _, Peripheral as _, ScanFilter};
use btleplug::platform::{Adapter, Manager, PeripheralId};
use futures::StreamExt;
use uuid::Uuid;

use crate::emit::{self, ScanLine, SwbError};

/// 16-bit UUID 0xfd3d expanded to the Bluetooth base UUID: the SwitchBot
/// service-data key.
const FD3D: Uuid = Uuid::from_u128(0x0000fd3d_0000_1000_8000_00805f9b34fb);

/// Assemble one JSONL line. `mfr_payload` arrives without the company ID
/// (btleplug strips it); `mfr_hex` re-prepends the little-endian company
/// ID so the emitted hex matches the over-the-air bytes.
pub fn build_line(
    ts: String,
    addr: String,
    rssi: Option<i16>,
    mfr_payload: &[u8],
    svc_payload: Option<&[u8]>,
) -> ScanLine {
    let decoded = parse::decode(Some(mfr_payload), svc_payload);
    let mut mfr_hex = String::from("6909");
    mfr_hex.push_str(&emit::hex(mfr_payload));
    let (model, values) = match decoded {
        Some(d) => (Some(d.model), Some(d.values)),
        None => (None, None),
    };
    ScanLine {
        ts,
        addr,
        rssi,
        mfr_hex: Some(mfr_hex),
        svc_hex: svc_payload.map(emit::hex),
        model,
        values,
    }
}

/// Run the scan loop until interrupted (`follow`) or until `timeout_secs`
/// elapses (`--once`, deduplicated per device).
pub fn run_scan(follow: bool, timeout_secs: u64) -> Result<(), SwbError> {
    let rt = tokio::runtime::Builder::new_current_thread()
        .enable_all()
        .build()
        .map_err(|e| SwbError::other(format!("tokio runtime: {e}")))?;
    rt.block_on(scan(follow, timeout_secs))
}

async fn scan(follow: bool, timeout_secs: u64) -> Result<(), SwbError> {
    let manager = Manager::new().await.map_err(adapter_err)?;
    let central = manager
        .adapters()
        .await
        .map_err(adapter_err)?
        .into_iter()
        .next()
        .ok_or_else(|| SwbError::adapter("no BLE adapter found"))?;
    let mut events = central.events().await.map_err(adapter_err)?;
    central
        .start_scan(ScanFilter::default())
        .await
        .map_err(adapter_err)?;
    tracing::info!(follow, timeout_secs, "BLE scan started");

    let deadline = tokio::time::Instant::now() + Duration::from_secs(timeout_secs);
    let mut seen: HashSet<String> = HashSet::new();
    let mut emitted = 0usize;

    loop {
        let event = if follow {
            events.next().await
        } else {
            match tokio::time::timeout_at(deadline, events.next()).await {
                Ok(event) => event,
                Err(_) => break, // collection window elapsed
            }
        };
        let Some(event) = event else { break };

        if let CentralEvent::ManufacturerDataAdvertisement {
            id,
            manufacturer_data,
        } = event
        {
            let Some(payload) = manufacturer_data.get(&parse::COMPANY_ID) else {
                continue;
            };
            let Some(line) = assemble(&central, &id, payload).await else {
                continue;
            };
            if !follow && !seen.insert(line.addr.clone()) {
                continue;
            }
            emit::print_json(&line);
            emitted += 1;
        }
    }

    let _ = central.stop_scan().await;
    if !follow && emitted == 0 {
        return Err(SwbError::timeout(format!(
            "no SwitchBot advertisement received within {timeout_secs}s"
        )));
    }
    Ok(())
}

/// Pull address/rssi/service-data from the peripheral cache and build the
/// line. Failures here just skip the event — never break the stream.
async fn assemble(central: &Adapter, id: &PeripheralId, mfr_payload: &[u8]) -> Option<ScanLine> {
    let peripheral = central.peripheral(id).await.ok()?;
    let props = peripheral.properties().await.ok().flatten()?;
    let svc = props.service_data.get(&FD3D).map(Vec::as_slice);
    Some(build_line(
        emit::now_ts(),
        props.address.to_string(),
        props.rssi,
        mfr_payload,
        svc,
    ))
}

fn adapter_err(e: btleplug::Error) -> SwbError {
    SwbError::adapter(format!("BLE adapter error: {e}"))
}

```rust
//! clap parsing and dispatch only — all logic lives in the library.

use clap::error::ErrorKind as ClapErrorKind;
use clap::{ArgGroup, Parser, Subcommand};
use serde_json::{json, Value};

use swb::emit::{self, SwbError};
use swb::{ble, cloud, config};

#[derive(Parser)]
#[command(name = "swb", version, about = "UNIX-philosophy CLI for SwitchBot devices")]
struct Cli {
    #[command(subcommand)]
    command: Command,
}

#[derive(Subcommand)]
enum Command {
    /// BLE passive scan; emits JSONL on stdout
    #[command(group(ArgGroup::new("mode").required(true).args(["follow", "once"])))]
    Scan {
        /// Scan continuously
        #[arg(long)]
        follow: bool,
        /// Single collection pass (one line per device), then exit
        #[arg(long)]
        once: bool,
        /// Collection window in seconds for --once (config default_timeout, else 10)
        #[arg(long)]
        timeout: Option<u64>,
    },
    /// List models with BLE decode support (static info)
    Models,
    /// Cloud: list devices
    Devices,
    /// Cloud: fetch device status
    Status {
        /// Device ID or config alias
        device: String,
    },
    /// Cloud: send a control command
    Cmd {
        /// Device ID or config alias
        device: String,
        /// Command name, e.g. turnOn
        command: String,
        /// Command parameter as JSON (plain strings allowed); default "default"
        #[arg(long)]
        param: Option<String>,
    },
}

fn main() {
    tracing_subscriber::fmt()
        .with_writer(std::io::stderr)
        .with_env_filter(tracing_subscriber::EnvFilter::from_default_env())
        .init();

    let cli = match Cli::try_parse() {
        Ok(cli) => cli,
        Err(e)
            if matches!(
                e.kind(),
                ClapErrorKind::DisplayHelp | ClapErrorKind::DisplayVersion
            ) =>
        {
            let _ = e.print();
            std::process::exit(0);
        }
        Err(e) => exit_with(SwbError::usage(e.to_string())),
    };

    if let Err(e) = run(cli) {
        exit_with(e);
    }
}

fn exit_with(e: SwbError) -> ! {
    eprintln!("{}", e.to_json());
    std::process::exit(e.kind.exit_code());
}

fn run(cli: Cli) -> Result<(), SwbError> {
    match cli.command {
        Command::Scan {
            follow,
            once: _,
            timeout,
        } => {
            let cfg = config::load()?;
            let timeout = timeout.or(cfg.default_timeout).unwrap_or(10);
            ble::run_scan(follow, timeout)
        }
        Command::Models => {
            let models: Vec<Value> = ble::parse::MODELS
                .iter()
                .map(|m| {
                    json!({
                        "model": m.model,
                        "tag": m.tag.to_string(),
                        "values": m.values,
                    })
                })
                .collect();
            emit::print_json(&models);
            Ok(())
        }
        Command::Devices => {
            let cfg = config::load()?;
            let body = client(&cfg)?.get("/v1.1/devices")?;
            emit::print_json(&body);
            Ok(())
        }
        Command::Status { device } => {
            let cfg = config::load()?;
            let id = cfg.resolve_device(&device);
            let mut body = client(&cfg)?.get(&format!("/v1.1/devices/{id}/status"))?;
            attach_device_id(&mut body, &id);
            emit::print_json(&body);
            Ok(())
        }
        Command::Cmd {
            device,
            command,
            param,
        } => {
            let cfg = config::load()?;
            let id = cfg.resolve_device(&device);
            let parameter = match &param {
                // JSON if it parses, otherwise treat the raw text as a string
                Some(p) => serde_json::from_str(p).unwrap_or_else(|_| Value::String(p.clone())),
                None => Value::String("default".to_string()),
            };
            let payload = json!({
                "command": command,
                "parameter": parameter,
                "commandType": "command",
            });
            let mut body = client(&cfg)?.post(&format!("/v1.1/devices/{id}/commands"), &payload)?;
            attach_device_id(&mut body, &id);
            emit::print_json(&body);
            Ok(())
        }
    }
}

fn client(cfg: &config::Config) -> Result<cloud::Client, SwbError> {
    let (token, secret) = cfg.credentials(env_var("SWITCHBOT_TOKEN"), env_var("SWITCHBOT_SECRET"))?;
    Ok(cloud::Client::new(token, secret))
}

fn env_var(name: &str) -> Option<String> {
    std::env::var(name).ok().filter(|v| !v.is_empty())
}

fn attach_device_id(body: &mut Value, id: &str) {
    if let Value::Object(map) = body {
        map.insert("device_id".to_string(), Value::String(id.to_string()));
    }
}
```

```markdown
# swb

A UNIX-philosophy CLI for SwitchBot devices. Reads sensors over **BLE
passive scanning** (no hub, no cloud, no rate limits) and controls devices
through the **SwitchBot Cloud API v1.1** — nothing else. Aggregation,
storage, and dashboards are downstream jobs for tools like `jq`, Vector,
or SQL.

- stdout is pure structured JSON (JSONL in scan mode) — pipe it anywhere
- diagnostics and errors go to stderr as structured logs
- unknown devices are emitted losslessly instead of breaking the stream
- headless-friendly: plain token+secret auth, works in cron and Docker

## Install

```sh
cargo install --path .
```

Linux needs BlueZ and `libdbus-1-dev`/`pkg-config` at build time (or build
with `--features vendored-dbus`). BLE scanning may require
`setcap 'cap_net_raw,cap_net_admin+eip'` on the binary or running as a
user with Bluetooth privileges.

## Quick start — BLE (primary)

```sh
# one collection pass, one line per device
swb scan --once --timeout 15

# continuous stream
swb scan --follow
```

Example line (Meter Pro CO2):

```json
{"ts":"2026-07-14T06:00:00.123Z","addr":"XX:XX:XX:XX:XX:XX","rssi":-61,"mfr_hex":"6909...","svc_hex":"350064","model":"MeterProCO2","values":{"battery":88,"co2":712,"humidity":52,"temperature":24.5}}
```

Schema:

| field | presence | meaning |
|---|---|---|
| `ts` | always | receive time, RFC 3339 UTC, millisecond precision |
| `addr` | always | device MAC (platform-specific ID on macOS) |
| `rssi` | when known | signal strength, dBm |
| `mfr_hex` | always | raw manufacturer data, hex, incl. little-endian company ID (`6909`) — the lossless layer |
| `svc_hex` | when present | raw `0xfd3d` service data, hex |
| `model` / `values` | when decoded | added only when the decode dictionary matches; never guessed, never null |

`swb models` lists the models with decode support. Unknown models still
produce raw lines.

Pipe to [Vector](https://vector.dev):

```toml
[sources.co2]
type = "exec"
mode = "streaming"
command = ["swb", "scan", "--follow"]

[transforms.parse]
type = "remap"
inputs = ["co2"]
source = ". = parse_json!(.message)"
```

## Quick start — Cloud API (secondary)

Get a token and secret from the SwitchBot app (Profile → Preferences →
Developer Options), then:

```sh
export SWITCHBOT_TOKEN=... SWITCHBOT_SECRET=...

swb devices                     # list devices
swb status DEVICE_ID            # fetch status
swb cmd DEVICE_ID turnOn        # send a command
swb cmd DEVICE_ID setMode --param '{"mode":"auto"}'
```

`DEVICE_ID` can be an alias from the config file — see
[`config.example.toml`](config.example.toml).

The cloud backend is for actuation and out-of-range devices; sensor
polling belongs on the BLE side. Rate limit: 10,000 calls/day per account;
swb never polls on its own.

## Exit codes

| code | meaning |
|---|---|
| 0 | success |
| 2 | usage error |
| 3 | timeout (nothing received / request timed out) |
| 4 | BLE adapter missing or insufficient permissions |
| 5 | auth error (missing/invalid credentials) |
| 6 | device rejected / API returned non-success statusCode |
| 1 | other |

Errors are one JSON line on stderr: `{"error":{"kind":"...","detail":"..."}}`.

## Stability

The output schema is documented and kept stable — LLM function calling and
downstream SQL depend on it. Breaking changes bump the minor version even
pre-1.0.
